# TMRW—KeyFlow

ส่วนเสริมสลับ API key อัตโนมัติสำหรับ SillyTavern โดย **tmrw**

KeyFlow จะใช้คีย์เดิมต่อไปจนเกิดข้อผิดพลาดแล้วจึงสลับไปคีย์ถัดไปและลองส่งคำขอเดิมใหม่ 1 ครั้ง รองรับ Google AI Studio ทั้งคีย์ `AIza…` และ `AQ.…` รวมถึง OpenRouter `sk-or-…`

## จุดเด่น

- สลับเฉพาะเมื่อเกิด error ที่เลือกไว้: `401/403`, `429`, `402` และ `5xx` แบบเลือกเปิดได้
- ไม่สลับทุกข้อความ
- เลือกติดตามผู้ให้บริการตามแหล่งที่มาของ Chat Completion ได้อัตโนมัติ และปิดฟังก์ชันนี้ได้
- รายการคีย์แบบพับเก็บ ค้นหาได้ และแบ่งหน้า 
- ถ้าพบคีย์ 30 อันขึ้นไป จะมีเครื่องมือจัดการจำนวนมากอยู่ในหัวข้อ “จัดการคีย์” เพื่อเก็บคีย์ที่ใช้อยู่ไว้ 1 อันหรือลบทั้งหมด
- ตรวจพบ `allowKeysExposure: true` และมีปุ่มคัดลอกคำสั่งแก้สำหรับ Termux พร้อมตรวจซ้ำอัตโนมัติหลังรีสตาร์ต
- เพิ่มหลายคีย์พร้อมกัน เปลี่ยนชื่อ เลือกใช้ ลบ และพักคีย์ที่มีปัญหาได้
- มีเมนู **ตรวจสอบคำขอล่าสุด** เก็บเฉพาะ 2 ปัญหาล่าสุด พร้อมผลก่อนและหลังสลับคีย์ สาเหตุ เวลา Provider, Model และข้อมูลอุปกรณ์แบบทั่วไป
- คัดลอกรายงานที่ตัด API key, Prompt, เนื้อหาแชท, Request body, Cookie และ Token ออกแล้ว เพื่อส่งให้ผู้ช่วยวิเคราะห์ได้จาก iOS หรือเว็บเช่า
- มีปุ่มส่งคำขอทดสอบสั้น ๆ ด้วยโมเดลที่เลือกอยู่ (อาจใช้โควตาเล็กน้อย)

## ติดตั้งผ่าน Termux

1. ดาวน์โหลด ZIP ไว้ในโฟลเดอร์ **Download**
2. ปิด SillyTavern ด้วย `Ctrl+C`
3. เปิดไฟล์ `INSTALL-TERMUX.txt` แล้วคัดลอกคำสั่งทั้งก้อนไปวาง
4. เปิด SillyTavern ใหม่ แล้วเข้า **Extensions → TMRW—KeyFlow**

หากติดตั้ง ZerxzLib อยู่ ให้ปิดหรือลบก่อนใช้ KeyFlow เพื่อป้องกันสองส่วนเสริมสลับคีย์พร้อมกัน การลบส่วนเสริมจะไม่ลบ API key ที่ SillyTavern เก็บไว้

## ความปลอดภัย

คีย์จริงจะถูกส่งไปยัง secret manager ของ SillyTavern โดยตรง KeyFlow อ่านเพียง ID ชื่อ สถานะ และค่าที่ถูกปิดบัง ไม่บันทึกคีย์จริงไว้ใน extension settings หรือ log

รายงานวิเคราะห์เก็บเฉพาะข้อมูลทางเทคนิคที่จำเป็น และผ่านการตัดคีย์ โทเคน คุกกี้ พรอมพ์ เนื้อหาแชท และ request body ออกก่อนบันทึก รายงานเก็บเฉพาะ 2 ปัญหาล่าสุดใน settings ของส่วนเสริม และไม่เก็บคำขอทดสอบที่สำเร็จ
